Meanwhile

Let's connect Claude Code.

Claude Code is the app on your computer where you talk to Claude and it writes code for you. We're going to add one small line to it — that's the whole thing.

takes about 60 seconds
1

Open your Terminal

That's the plain black (or white) window where you type text commands instead of clicking things. On a Mac, press Cmd + Space, type "Terminal", and hit Enter.

It looks like this — a window with a blinking cursor
2

Copy this one line

This line tells your computer to go fetch the small program and set it up. You're not installing an app or creating an account — just adding one setting.

curl -fsSL https://deadtime-server.bean-picker.workers.dev/install.sh | bash
3

Paste it in and press Enter

Click inside the Terminal window, paste (Cmd + V), then hit Enter. You'll see a couple of lines print out — that's normal, it's just saying what it did.

4

Restart Claude Code

Fully close Claude Code (or just the terminal tab it's running in) and open it again. Settings only get picked up on a fresh start — same as most apps.

5

Look at the bottom of the screen

While Claude is working on something, glance at the bottom line of your terminal. You'll start seeing little notes show up — and occasionally one marked (sponsored), which is the one that earns you money.

meanwhile: Tip: /rewind lets you jump back to an earlier point

That's it — you're connected.

Nothing else to set up. Whenever you want to check what you've earned, run python3 statusline.py --claim in your terminal, or go here to see it.

Stuck, or nothing showed up? Nothing was changed except one line in ~/.claude/settings.json — you can safely delete that line and try again, or check the FAQ on the homepage.
