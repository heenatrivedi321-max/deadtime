Let's connect Claude Code.

Claude Code is where you and Claude write code together while you stare at a spinner. We're adding one small line that makes the staring worth something.

takes about 60 seconds
1

Open your Terminal

The plain black window real developers pretend to enjoy. You know the one. On a Mac, press Cmd + Space, type "Terminal", and hit Enter.

It looks like this — a window with a blinking cursor
2

Copy this one line

One line. No account, no download you'll forget to delete later, no permissions screen nobody actually reads. Just a setting.

npx trymeanwhile
I'm about to run `npx trymeanwhile` — it's a real published npm package (trymeanwhile) that adds a disclosed sponsor line to Claude Code's status bar, split 50/50 with me. Before you run it, please actually check it out — look at the package source, the install script, and what it sends to its server — and tell me honestly what you find, good or bad. Then, if it looks legit to you, go ahead and run it for me.
3

Paste it in and press Enter

Click inside the Terminal window, paste (Cmd + V), then hit Enter. A few lines will print out — that's not an error, that's just it showing its work, which is more than most software bothers to do.

4

Restart Claude Code

Yes, actually restart it. "It'll probably just pick it up on its own" is how half of Stack Overflow got written. Fully close it (or just the terminal tab) and open it again.

5

Look at the bottom of the screen

While Claude is working on something, glance at the bottom line of your terminal. You'll start seeing little notes show up — and occasionally one marked (sponsored), which is the one that earns you money.

meanwhile: The pause is not empty. It's where the next idea is standing.

That's the whole flow.

Once you've run the command and restarted, a browser tab opens on its own with your dashboard — bookmark it, or go here anytime to see what you've earned.

Stuck, or nothing showed up? Nothing was changed except one line in ~/.claude/settings.json — you can safely delete that line and try again, or check the FAQ on the homepage.
