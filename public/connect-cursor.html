1

Let your agent install it

Paste this into Cursor's agent — it's a normal CLI install by extension ID, the same way you'd install anything else, not some file you have to trust blind:

cursor --install-extension meanwhile-dev.meanwhile
I'm about to install the "meanwhile-dev.meanwhile" extension via `cursor --install-extension meanwhile-dev.meanwhile` — it's the real, published listing for Meanwhile, which adds a disclosed sponsor line to Cursor's status bar, split 50/50 with me. Before you run it, please actually check it out — look at the extension's listing and source if you can — and tell me honestly what you find, good or bad. Then, if it looks legit to you, go ahead and install it for me.

Or do it by hand: Cmd/Ctrl+Shift+X → search meanwhile-dev.meanwhile → Install.

Look at the bottom-right of the window

While you're actively typing, quiet lines will start showing up — occasionally one marked (sponsored), which is the one that actually pays you.
