Meanwhile

Let's connect VS Code.

This one's a direct install, not a Marketplace listing yet — a real, working extension, just not searchable inside VS Code's Extensions panel yet. That part's still in progress.

takes about a minute
This extension doesn't hook into Copilot or read any other extension's state — VS Code has no public API for that. It's a quiet line while you're actively coding, using only its own status bar item. Nothing patched, nothing hidden. Full source →
1

Download the extension

This is a .vsix file — VS Code's own installable extension package format, the same format the Marketplace itself uses under the hood.

⬇ Download meanwhile.vsix
2

Install it into VS Code

Easiest way: open VS Code, open the Command Palette (Cmd+Shift+P / Ctrl+Shift+P), type "Install from VSIX", and pick the file you just downloaded. Or from a terminal:

code --install-extension ~/Downloads/meanwhile.vsix
3

Trust the folder you're working in

VS Code's own Workspace Trust feature blocks third-party extensions in folders it doesn't recognize yet. If nothing shows up, look for a "Trust this folder" prompt (usually on first opening a new project) and accept it — this is a VS Code security feature, not something specific to this extension.

4

Look at the bottom-right of the window

While you're actively typing, glance at the status bar. You'll start seeing quiet lines show up — and occasionally one marked (sponsored), which is the one that earns you money.

That's it — you're connected.

Already using Meanwhile with Claude Code or Copilot CLI? Same install ID, same balance — everything adds up together. Click the status bar item any time, or run the Meanwhile: Check Earnings command from the Command Palette, to see what you've earned.

Stuck? Uninstall like any other extension — nothing else on your machine is touched. Or check the FAQ on the homepage.
